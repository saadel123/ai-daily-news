💡 Hack des Tages · Tip of the day

Claude Code 2.1.219 · MCP-Fehlerdiagnose auf einen Blick
Deutsch

Klein, aber fein: In Claude Code 2.1.219 zeigt der MCP-Listbefehl jetzt den HTTP-Status und den Fehlertext, wenn ein MCP-Server sich nicht verbinden lässt. Bisher hat die Übersicht Server stillschweigend ohne jede Erklärung aufgeführt — jetzt siehst du direkt den genauen Fehlercode und die Fehlermeldung. Das macht das Debugging kaputter MCP-Setups deutlich schneller: ein Blick genügt, und du weißt sofort, ob der Server mit einem HTTP-Fehler streikt oder ob der Config-Eintrag selbst das Problem ist.

English

Small but neat: Claude Code 2.1.219 now shows the HTTP status and error text in the MCP list view when a server fails to connect. Previously the list would silently include a server without any explanation of why it wasn't responding — now you get the exact error code and message right there. That makes debugging broken MCP setups noticeably faster: one glance tells you whether the server is returning an HTTP error or whether the config entry itself is the problem.
