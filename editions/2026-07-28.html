💡 Hack des Tages · Tip of the day

Claude Code 2.1.217 · Emoji-Kürzel im Prompt
Deutsch

Claude Code 2.1.217 bringt Emoji-Kürzel-Autocomplete direkt ins Prompt-Eingabefeld: Tipp ein Kürzel wie `:heart:` und ein Dropdown mit passenden Emojis klappt auf, genau wie in Slack oder GitHub. Das Feature lässt sich per Einstellungsdatei deaktivieren, wenn man lieber ohne arbeitet. Außerdem mahnt Claude Code jetzt, wenn Transkript-Schreibvorgänge fehlschlagen oder das Session-Speichern durch eine geerbte Umgebungsvariable stumm deaktiviert wird.

English

Claude Code 2.1.217 adds emoji shortcode autocomplete in the prompt input field: type a shortcode like :heart: and a dropdown pops up with matching emojis, just like Slack or GitHub. The feature can be toggled off via your settings file if you prefer to skip it. Claude Code also now warns when transcript writes fail or when session saving has been silently disabled by an inherited environment variable — finally surfacing those quiet config mistakes.

BEFEHL · COMMAND
:emoji-name:   # im Prompt-Eingabefeld · in the prompt input
emojiCompletionEnabled
boolean in settings.json; set to false to disable the emoji shortcode dropdown
# Emoji-Dropdown auslösen · Trigger emoji dropdown
:heart:  →  ❤️
