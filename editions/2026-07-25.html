Claude Code 2.1.219 · Opus 5 als Default + strictAllowlist
Deutsch

Claude Code 2.1.219 stellt Claude Opus 5 als neues Default-Modell ein — mit Millionen-Token-Kontext und Fast Mode für zehn Dollar Input, 50 Dollar Output pro Mio. Tokens. Neu dazu kommt das strictAllowlist-Setting in der settings.json: Hosts, die nicht auf der Liste stehen, werden in Sandbox-Befehlen ohne Rückfrage blockiert — praktisch für Teams, die strikte Netzwerkkontrolle brauchen, ohne bei jedem Tool-Call unterbrochen zu werden. English

Claude Code 2.1.219 sets Claude Opus 5 as the new default model — with a million-token context and Fast Mode at $10 input / $50 output per million tokens. New alongside it: the strictAllowlist setting in settings.json — hosts not on the list are blocked without prompting in sandboxed commands, handy for teams that need strict network control without interruptions on every tool call. Agent delegation is also more formally anchored: the Agent tool entry in the system prompt now explicitly describes that Claude Code can hand off complex tasks to independent subagents.

BEFEHL · COMMAND
sandbox.network.strictAllowlist [in .claude/settings.json]
[]
empty array — block all non-allowlisted hosts silently in sandboxed commands
["host", "*.domain.com"]
array of exact hostnames or wildcard patterns to allow without prompting
# Nur GitHub API und PyPI erlauben · Allow only GitHub API and PyPI
$ cat .claude/settings.json
{
  "sandbox": {
    "network": { "strictAllowlist": ["api.github.com", "*.pypi.org"] }
  }
}

# Alle Hosts stumm blockieren · Block all non-listed hosts silently
$ cat .claude/settings.json
{ "sandbox": { "network": { "strictAllowlist": [] } } }
