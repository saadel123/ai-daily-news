💡 Hack des Tages · Tip of the day

Claude Code 2.1.219 · /add-dir · DirectoryAdded Hook
Deutsch

Seit Claude Code 2.1.219 kennt Claude Code einen neuen Hook-Event: DirectoryAdded. Er feuert jedes Mal, wenn du im laufenden Chat den Slash-Command /add-dir aufrufst und ein neues Arbeitsverzeichnis zur Session registrierst. Du kannst damit Skripte automatisch starten, sobald Claude Code in ein neues Repo einzieht — eine virtuelle Umgebung aktivieren, Dependencies prüfen oder eine projektspezifische CLAUDE.md vorladen. Konfiguriert wird der Hook wie alle anderen in settings.json unter dem Schlüssel DirectoryAdded — plus dem Script-Pfad, den du ausführen willst.

English

Claude Code 2.1.219 introduces a new hook event: DirectoryAdded. It fires every time you use /add-dir in an active chat to register a new working directory to your session. Use it to automatically kick off scripts when Claude Code enters a new repo — activate a virtual environment, check dependencies, or pre-load a project-specific CLAUDE.md. Configure it in settings.json under the DirectoryAdded key, just like any other Claude Code hook, pointing to the script you want to run.

BEFEHL · COMMAND
/add-dir <path>
# Hilfsbibliothek zur laufenden Session hinzufügen · Add a helper lib mid-session
$ /add-dir ~/code/shared-utils

# Hook feuert danach automatisch · Hook fires automatically after
$ cat .claude/settings.json | grep -A4 DirectoryAdded
