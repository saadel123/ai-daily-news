Claude Code 2.1.219 · Subagenten Tiefe 3
Deutsch

Claude Code 2.1.219 hebt die maximale Verschachtelungstiefe für Subagenten auf drei — bisher war nach der ersten Ebene Schluss. Das bedeutet: Ein Agent kann jetzt Agenten spawnen, die selbst wieder Agenten spawnen, und das dreifach tief. Neu dabei: eine Sandbox-Einstellung blockt alle nicht explizit erlaubten Hosts für Sandbox-Befehle, ohne extra Prompt. Außerdem gibt es den DirectoryAdded-Hook, der feuert, wenn du im Lauf einer Session ein neues Working Directory registrierst.

English

Claude Code 2.1.219 raises the maximum nesting depth for subagents to three — previously one level was the limit. That means an agent can now spawn agents that themselves spawn agents, three levels deep. New: a sandbox network setting silently blocks all non-allowlisted hosts in sandboxed commands with no extra prompts. There is also a new DirectoryAdded hook that fires whenever a new working directory is registered mid-session.

BEFEHL · COMMAND
CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=<depth>  claude
CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH
max nesting depth for spawned subagents (default: 3, previous default was 1)
sandbox.network.strictAllowlist
in settings.json — deny non-allowlisted hosts in sandboxed commands without a prompt
# Tiefe auf 1 zurücksetzen (altes Verhalten) · Revert to single-level nesting
$ CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 claude

# Strikte Netzwerkliste im Projekt aktivieren · Enable strict network allowlist
$ echo '{"sandbox":{"network":{"strictAllowlist":true}}}' >> .claude/settings.json

Claude Code 2.1.217 · Budget-Stopp und Emoji-Shortcodes
Deutsch

Claude Code 2.1.217 bringt drei praktische Ergänzungen. Erstens: Emoji-Shortcodes direkt im Chat — gib einfach Doppelpunkt plus Wortname ein, und Claude ersetzt es durch das passende Emoji, konfigurierbar in den Settings. Zweitens: Ein Budget-Flag stoppt jetzt auch Hintergrund-Subagenten, wenn das Dollar-Limit aufgebraucht ist — kein unerwarteter Kostenschub mehr. English

Claude Code 2.1.217 ships three practical additions. First: emoji shortcodes right in the chat — just type a colon followed by the emoji name and Claude substitutes the right emoji; configurable in settings. Second: a budget flag now also stops background subagents when the dollar limit is spent — no more surprise cost spikes. Third: the maximum number of concurrent subagents defaults to 20 and can be tuned via environment variable.

BEFEHL · COMMAND
claude [--max-budget-usd <amount>] [options]
--max-budget-usd <amount>
stop all agents including background subagents once total USD spend hits this limit
CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS
cap the number of subagents running in parallel (default: 20)
emojiCompletionEnabled
settings.json key — set to false to disable the :shortcode: → emoji autocomplete
# Budgetgrenze setzen, alle Agenten stoppen wenn erreicht · Stop all agents at budget cap
$ claude --max-budget-usd 2.50

# Parallele Subagenten begrenzen · Limit concurrent subagents
$ CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS=5 claude
